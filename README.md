# Abdulmajeed Alshammari — Portfolio

A bilingual English/Arabic static portfolio built with HTML, CSS, and JavaScript. No build step is required.

## Local preview

Open `index.html` in a browser.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site from the `main` branch. Select **GitHub Actions** under **Settings → Pages**. Once the repository is public and the first workflow succeeds, the site URL is `https://abdulmajeed-fahad.github.io/portfolio/`.

## Images

Add the image files referenced by `index.html` under `assets/`: `profile.jpg`, `projects/smart-fab-lab.jpg`, `projects/mustame.jpg`, and the certificate images under `certs/`. They were not included with the supplied HTML.
