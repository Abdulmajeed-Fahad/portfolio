# Abdulmajeed Alshammari — Portfolio

A bilingual English/Arabic static portfolio built with HTML, CSS, and JavaScript, with a dark/light theme toggle. No build step is required.

## Local preview

Open `index.html` in a browser.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site from the `main` branch. Select **GitHub Actions** under **Settings → Pages**. Once the repository is public and the first workflow succeeds, the site URL is `https://abdulmajeed-fahad.github.io/portfolio/`.

## Images

Project images live in `assets/projects/` (`drone-ppe.jpg` and `makeen.jpg` are included; add `smart-fab-lab.jpg` and `mustame.jpg`).

Certificate images go in `assets/certs/` with the file names used in `index.html` (for example `data-science-ai.jpg`, `cisco-iot.jpg`, `tuwaiq-mechatronics.jpg`, `tuwaiq-esp32.jpg`, `safcsp-drones.jpg`, `uoh-appreciation.jpg`, `makeen-hackathon.jpg`, `tuwaiq-engineering-design.jpg`). Until an image is added, the certificate shows a badge icon instead.
